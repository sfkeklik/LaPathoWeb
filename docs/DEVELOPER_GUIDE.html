Patoloji Görüntü Anotasyon Sistemi - Geliştirici Kılavuzu

1. Proje Genel Bakış

LaPatho, patoloji görüntülerinin yüklenmesi, işlenmesi, görüntülenmesi ve anotasyonlanması için geliştirilmiş modern bir web uygulamasıdır. Yüksek çözünürlüklü WSI (Whole Slide Images) formatlarını destekler ve profesyonel anotasyon araçları sunar.

2.2 Backend Kurulum

Adım 1: Projeyi Klonlama

git clone https://github.com/your-repo/LaPatho.git cd LaPatho

Adım 2: PostgreSQL Veritabanı Oluşturma

PostgreSQL kurulu ve çalışıyor olmalıdır. Aşağıdaki komutları çalıştırın:

# PostgreSQL'e bağlan psql -U postgres # Veritabanı ve kullanıcı oluştur CREATE DATABASE lapatho; CREATE USER lapatho WITH PASSWORD 'password'; GRANT ALL PRIVILEGES ON DATABASE lapatho TO lapatho; \q

Adım 3: Konfigürasyon Kontrolü

src/main/resources/application.properties dosyasını kontrol edin:

# Veritabanı bağlantı ayarları spring.datasource.url=jdbc:postgresql://localhost:5432/lapatho spring.datasource.username=lapatho spring.datasource.password=password # Tile ve upload dizinleri (kendi sisteminize göre ayarlayın) tile.output-base-path=C:/Users/user/Desktop/LaPatho/tiles upload.base-path=uploads

Adım 4: Maven ile Build ve Çalıştırma

# Windows .\mvnw.cmd spring-boot:run # Linux/Mac ./mvnw spring-boot:run
✅ Başarılı! Backend http://localhost:8080 adresinde çalışmaya başlayacaktır.

İlk Çalıştırma - Veritabanı Şeması

İlk çalıştırmada veritabanı tablolarının oluşturulması için:

# application.properties'de şema modunu değiştirin (sadece ilk kez) spring.sql.init.mode=always # Sonra tekrar 'never' yapın spring.sql.init.mode=never

3. Backend Mimarisi

LaPatho backend'i Spring Boot framework üzerine inşa edilmiştir ve klasik katmanlı mimari (Layered Architecture) kullanır. Her katman belirli bir sorumluluğa sahiptir ve katmanlar arası iletişim dependency injection ile sağlanır.

3.1 Katman Yapısı

🌐 Controller Layer
REST API Endpoints
⬇️ DTO ⬇️

İş Mantığı (Business Logic)
⬇️ Entity ⬇️

3.2 Entity Sınıfları

Entity sınıfları JPA (Java Persistence API) anotasyonları ile veritabanı tablolarına map edilir. Lombok kütüphanesi boilerplate kodu azaltmak için kullanılır.

📌 ImageEntity

Görüntü dosyalarının metadata bilgilerini tutar.

@Entity @Table(name = "images") @Data // Lombok: getter, setter, toString, equals, hashCode @NoArgsConstructor @AllArgsConstructor public class ImageEntity { @Id @GeneratedValue(strategy = GenerationType.IDENTITY) private Long id; private String name; // Dosya adı private int width, height; // Piksel boyutları private int tileSize; // Tile boyutu (varsayılan: 512) private int maxLevel; // Maksimum zoom seviyesi private String path; // Dosya yolu @Enumerated(EnumType.STRING) private Status status; // PENDING, PROCESSING, READY, ERROR // Metadata alanları private Long fileSize; // Dosya boyutu (byte) private String format; // TIFF, BIF, SVS, etc. private Double pixelSizeX, pixelSizeY; // Piksel boyutları (µm) private Integer bitDepth; // Bit derinliği private Integer channels; // Kanal sayısı (RGB=3) private String colorSpace; // RGB, Grayscale private Double magnification; // Büyütme oranı (40x, etc.) private String scanner; // Tarayıcı modeli }

📌 AnnotationEntity

Görüntü üzerindeki anotasyonları tutar. Geometry alanı W3C Web Annotation formatında JSON saklar.

@Entity @Table(name = "annotations") public class AnnotationEntity { @Id @GeneratedValue(strategy = GenerationType.IDENTITY) private Long id; @ManyToOne @JoinColumn(name = "image_id") private ImageEntity image; // İlişkili görüntü @ManyToOne @JoinColumn(name = "user_id") private User user; // Oluşturan kullanıcı private String type; // polygon, rectangle, ellipse, freehand @Column(columnDefinition = "TEXT") private String geometry; // W3C Annotation JSON private Instant created, updated; }

📌 User Entity

Spring Security UserDetails interface'ini implement eder.

@Entity @Table(name = "users") public class User implements UserDetails { @Id @GeneratedValue(strategy = GenerationType.IDENTITY) private Long id; @Column(unique = true, nullable = false) private String username; private String password; // BCrypt hash private String firstName, lastName; private String email; @Enumerated(EnumType.STRING) private Role role; // ADMIN, DOCTOR private boolean enabled; // UserDetails methods... @Override public Collection<? extends GrantedAuthority> getAuthorities() { return List.of(new SimpleGrantedAuthority("ROLE_" + role.name())); } }

📌 Project Entity

Proje entity'si many-to-many ilişkilerle doktorları ve görüntüleri birleştirir.

@Entity @Table(name = "projects") public class Project { @Id @GeneratedValue(strategy = GenerationType.IDENTITY) private Long id; private String name; private String description; private Integer gradeLevel; // Derecelendirme seviyesi (1-5) @ManyToMany @JoinTable(name = "project_doctors", ...) private Set<User> assignedDoctors; // Atanan doktorlar @ManyToMany @JoinTable(name = "project_images", ...) private Set<ImageEntity> images; // Projedeki görüntüler @OneToMany(mappedBy = "project", cascade = CascadeType.ALL) private Set<Label> labels; // Proje etiketleri @ManyToOne private User createdBy; }

📌 Label Entity

@Entity @Table(name = "labels") public class Label { @Id @GeneratedValue private Long id; @ManyToOne(fetch = FetchType.LAZY) private Project project; private String name; // Etiket adı (Tumor, Necrosis, etc.) private String color; // Hex renk kodu (#ff0000) private String description; }

3.3 Repository Layer

Repository'ler Spring Data JPA JpaRepository interface'ini extend ederek CRUD operasyonlarını otomatik sağlar. Özel sorgular @Query anotasyonu ile tanımlanır.

@Repository public interface ImageRepository extends JpaRepository<ImageEntity, Long> { // JpaRepository tüm temel CRUD metodlarını sağlar: // save(), findById(), findAll(), deleteById(), etc. } @Repository public interface AnnotationRepository extends JpaRepository<AnnotationEntity, Long> { // Method query - Spring Data otomatik SQL oluşturur List<AnnotationEntity> findByImageId(Long imageId); List<AnnotationEntity> findByImageIdAndUserId(Long imageId, Long userId); List<AnnotationEntity> findByUserId(Long userId); } @Repository public interface ProjectRepository extends JpaRepository<Project, Long> { // JPQL Query ile özel sorgu @Query("SELECT p FROM Project p JOIN p.assignedDoctors d WHERE d = :doctor AND p.active = true") List<Project> findByAssignedDoctor(@Param("doctor") User doctor); // Doktor bu görüntüye erişebilir mi? @Query("SELECT CASE WHEN COUNT(p) > 0 THEN true ELSE false END FROM Project p JOIN p.images i JOIN p.assignedDoctors d WHERE i.id = :imageId AND d.id = :doctorId") boolean canDoctorAccessImage(@Param Long imageId, @Param Long doctorId); }

3.4 Service Layer

Service katmanı iş mantığını içerir. Transaction yönetimi @Transactional anotasyonu ile sağlanır.

📌 ImageService Özeti

@Service @Slf4j // Lombok logger public class ImageService { @Autowired private ImageRepository imageRepository; @Autowired private TileService tileService; @Autowired private ApplicationEventPublisher events; // Desteklenen formatlar private static final List<String> SUPPORTED_EXTENSIONS = Arrays.asList( ".tiff", ".tif", ".bif", ".svs", ".ndpi", ".scn", ".png", ".jpg", ".jpeg" ); // Görüntü oluşturma - Bio-Formats ile metadata okuma public ImageDTO create(String name, String inputPath) { // 1. 3.5 Controller Layer

Controller'lar REST endpoint'lerini tanımlar ve HTTP request/response işlemlerini yönetir.

@RestController @RequestMapping("/api/images") @RequiredArgsConstructor public class ImageController { @Autowired private ImageService imageService; @GetMapping("/metadata/{id}") public ResponseEntity<ImageMetadataDTO> metadata(@PathVariable Long id) { return imageService.findById(id) .map(img -> ResponseEntity.ok(toMetadataDTO(img))) .orElse(ResponseEntity.notFound().build()); } @DeleteMapping("/{id}") public ResponseEntity<Void> deleteImage( @PathVariable Long id, @AuthenticationPrincipal User currentUser) { // Sadece ADMIN silebilir (Security config'de tanımlı) imageService.deleteImage(id); return ResponseEntity.noContent().build(); } }

3.6 Security Yapılandırması

Spring Security ile JWT tabanlı stateless authentication kullanılır.

@Configuration @EnableWebSecurity @EnableMethodSecurity public class SecurityConfig { @Bean public SecurityFilterChain securityFilterChain(HttpSecurity http) { http .csrf(AbstractHttpConfigurer::disable) .cors(cors -> cors.configurationSource(corsConfigurationSource())) .authorizeHttpRequests(auth -> auth // Public endpoints .requestMatchers("/api/auth/**").permitAll() .requestMatchers("/api/tiles/**").permitAll() // Admin only .requestMatchers("/api/admin/**").hasRole("ADMIN") // Authenticated .requestMatchers("/api/**").authenticated() ) .sessionManagement(session -> session.sessionCreationPolicy(SessionCreationPolicy.STATELESS)) .addFilterBefore(jwtAuthFilter, UsernamePasswordAuthenticationFilter.class); return http.build(); } }
🔐 JWT Token Akışı:
  1. Kullanıcı /api/auth/login endpoint'ine credentials gönderir
  2. Başarılı doğrulama sonrası JWT token döner
  3. Frontend token'ı Authorization: Bearer <token> header'ında gönderir
  4. JwtAuthenticationFilter her request'te token'ı doğrular

6.4 Guards (Route Koruması)

Angular functional guards kullanılarak route'lar korunur.

// auth.guard.ts export const authGuard: CanActivateFn = (route, state) => { const authService = inject(AuthService); const router = inject(Router); if (authService.isLoggedIn()) { return true; } router.navigate(['/login'], { queryParams: { returnUrl: state.url } }); return false; }; export const adminGuard: CanActivateFn = (route, state) => { const authService = inject(AuthService); if (authService.isLoggedIn() && authService.isAdmin()) { return true; } return false; };

6.5 Interceptors

HTTP interceptor'lar tüm request'lere JWT token ekler ve 401 hatalarını yakalar.

@Injectable() export class AuthInterceptor implements HttpInterceptor { intercept(request: HttpRequest<any>, next: HttpHandler): Observable<HttpEvent<any>> { const token = this.authService.getToken(); if (token) { request = request.clone({ setHeaders: { Authorization: `Bearer ${token}` } }); } return next.handle(request).pipe( catchError((error: HttpErrorResponse) => { if (error.status === 401) { this.authService.logout(); // Token expired } return throwError(() => error); }) ); } }

7. OpenSeadragon & Annotorious Entegrasyonu

LaPatho, yüksek çözünürlüklü patoloji görüntülerini görüntülemek için OpenSeadragon ve anotasyon yapmak için Annotorious kütüphanelerini kullanır.

7.1 Tile Sistemi

Büyük WSI (Whole Slide Images) dosyaları piramit yapısında tile'lara bölünerek sunulur. Bu sayede sadece görüntülenen bölge yüklenir.

Level 0 (En küçük)     Level 1              Level 2         ...    Level N (Orijinal)
┌────┐                ┌────┬────┐          ┌──┬──┬──┬──┐           ┌─┬─┬─┬─┬─┬─┬─┬─┐
│    │                │    │    │          │  │  │  │  │           │ │ │ │ │ │ │ │ │
│    │       →        ├────┼────┤     →    ├──┼──┼──┼──┤    →      ├─┼─┼─┼─┼─┼─┼─┼─┤
│    │                │    │    │          │  │  │  │  │           │ │ │ │ │ │ │ │ │
└────┘                └────┴────┘          └──┴──┴──┴──┘           └─┴─┴─┴─┴─┴─┴─┴─┘
1 tile                4 tiles              16 tiles                 N² tiles

📌 Tile URL Formatı

/api/tiles/{imageId}/{level}/{tileX}_{tileY}.jpg Örnek: /api/tiles/15/5/3_2.jpg → Image ID: 15 → Zoom Level: 5 → Tile Koordinatları: X=3, Y=2 → Dosya: tiles/15/5/tile_3_2.jpg

📌 Tile Hesaplama Formülleri

// Maksimum zoom seviyesi maxLevel = ceil(log2(max(width, height) / tileSize)) // Belirli seviyedeki ölçek scale = 1 / 2^(maxLevel - level) // Ölçeklenmiş boyutlar scaledWidth = originalWidth × scale scaledHeight = originalHeight × scale // Tile sayısı tilesX = ceil(scaledWidth / tileSize) tilesY = ceil(scaledHeight / tileSize)

8.3 Nginx Konfigürasyonu

# nginx.conf ana ayarları server { listen 80; root /usr/share/nginx/html; # Angular SPA routing location / { try_files $uri $uri/ /index.html; } # Backend API proxy location /api/ { proxy_pass http://backend:8080/api/; proxy_set_header Host $host; proxy_set_header X-Real-IP $remote_addr; # Büyük dosya upload için client_max_body_size 2048M; proxy_read_timeout 300s; } }
